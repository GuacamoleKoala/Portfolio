Theepotten &
Europeana Data

Hoe ontsluit je een collectie van duizenden theepotten via een API? Dit project onderzoekt de volledige datapijplijn: van het scrapen van Europeana-data tot het bouwen van interactieve dashboards in Tableau.

STEP_01

API & Harvesting

Het bevragen van de Europeana REST API om metadata over theepotten uit verschillende Europese collecties te verzamelen.

STEP_02

Data Cleaning

Van ruwe JSON naar gestructureerde data. Opschonen van dubbele entries en het standaardiseren van materiaal- en dateringsvelden.

STEP_03

Data Visualisatie

Het vertalen van metadata naar inzichten. Waar komen de theepotten vandaan en welke trends zien we door de eeuwen heen?

STEP_04

IIIF Integratie

Gebruik van International Image Interoperability Framework (IIIF) om hogeresolutiebeelden direct in de analyse te trekken.
